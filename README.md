## You may check those

### [Blueprints (b8s)](https://github.com/mahmoudalnkeeb/b8s)

A TypeScript platform for multi-provider AI agents and RAG. It uses BullMQ and Redis for background work, Qdrant for vector search, and supports Gemini, DeepSeek, and local Ollama models. I deployed it to AWS EC2 with Docker Swarm, Nginx, and GitHub Actions.

### [trello.auto](https://github.com/mahmoudalnkeeb/trello.auto)

A Node.js CLI built for reliable Trello automation by people and AI agents. It provides profiles, reusable workflow recipes, stable JSON output, and preview-confirmation tokens for write operations.
